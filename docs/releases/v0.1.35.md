# XR Launcher 0.1.35

Spatial workspace launcher for Android XR glasses, tablets, and large-screen hosts — with the phone as a companion touchpad.

**Tag:** `v0.1.35` · **versionCode:** 36 · **minSdk:** 34

This build polishes the large-screen host chrome, adds optional panel navigation arrows, Cardboard-style dwell click for head-tracked mouse-look, and documents multi-vendor glasses IMU probes.

## Highlights

### Large-screen / tablet host
- **Edit** moved from the bottom-right pill into the **top HUD** (pencil beside Settings); glasses keep the bottom Edit pill
- Optional **left/right panel arrows** (Settings → Panel navigation) ease the view to Desktop · Home · app planes · Tray
- All Apps open drawer gets **outside padding** and a **squarer** frosted plate

### Companion
- Toolbar split into **two rows** (look/input + session)
- **Dwell click** (Timelapse icon): Cardboard-style dial around the glasses cursor — only while **mouse-look (FPS) + glasses IMU** are both on; fills ~1s then fires a center click

### Docs & tooling
- README **Credits** for RayNeo IMU HID ([verncat OpenVR](https://github.com/verncat/RayNeo-Air-3S-Pro-OpenVR))
- [`docs/glasses-imu.md`](../glasses-imu.md) + [`scripts/imu/`](../../scripts/imu/) for listing/dumping RayNeo / XReal / Viture HID on Linux (no new in-app OEM drivers)

### Fixes
- Unit tests updated for snap-to-grid default and gradient look curve (Verify CI green again)

## Install

1. Download **`app-release.apk`** from the GitHub Release for `v0.1.35`.
2. `adb install -r app-release.apk` (uninstall first if swapping from a debug-signed build).
3. Set **XR Launcher** as Home; re-enable Accessibility / notification access if needed.
4. For dwell: companion → Head tracking + Mouse look → Timelapse. For panel arrows: host Settings → Panel navigation.
